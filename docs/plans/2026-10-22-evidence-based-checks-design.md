# 基于证据的本地检查改进

## 目标与边界

保留 macOS 的14项检查、现有账号切换及独立代理诊断协议。改进诊断精度与固定出口配置一致性，不把检查通过解释为账号获得官方许可或不会被停用。Windows/Linux 暂不同步，避免扩大变更范围。

相比引入新的第三方 IP 评分 API、后台巡检和自动换号，本轮采用现有探测数据加严格分级：依赖更少，无需新增凭据，可用假网络完整验证。实际账号状态由官方应用中的认证请求确认。

## 具体行为

1. ASN 名称未命中内置运营商列表时，显示“类型待核验”，不推断为机房。名单命中也只说明运营商名称，不证明物理住宅接入。
2. STUN 无响应显示提醒，不能证明所有 UDP 或 WebRTC 路径已被禁用；收到不同出口地址仍为失败。
3. 无认证 HTTP 探测分别说明401、403、429、5xx、网络故障。403不再显示为访问正常，也不能当作封号证明。无认证API401是预期状态，不能验证账号权限。
4. 可选私有文件 `~/.claude-switcher/expected-exit-ip` 保存一个 IPv4。文件不存在时沿用国家检查；配置非法、不可读或实际出口不匹配时，`check` 与 `checkdetail` 均失败。不会自动学习或覆盖固定值。
5. 48小时统计文案改为“不同IP个数”，保留全部既有历史，不将其描述为已知的官方风控阈值。
6. App显示“检查通过”或“有提醒”，在可启动状态仍能重新检查；信息页讲明范围、限制、原生CLI账号隔离和官方资料。

## 验证

- 隔离HOME、假curl和系统工具，覆盖Cogent/已知运营商/缺失ASN；STUN无响应、匹配及泄漏；HTTP各类状态；固定出口未设置、匹配、同国家不匹配、无效配置。
- 覆盖`check`与UI使用的`checkdetail`，保持14个已知键。
- 运行原有独立代理诊断回归、bash语法检查、SHA256清单和SwiftUI编译。
- 只读检查网络及账号设置未被修改。真实账号聊天不作为自动化测试步骤。
- 本地已安装版本的替换按仓库AGENTS.md单独处理，先生成可审核的测试及构建结果。
